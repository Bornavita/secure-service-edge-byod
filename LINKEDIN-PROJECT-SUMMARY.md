# LinkedIn Project Summary (copy-paste ready)

**Project Title**  
Secure Service Edge for BYOD using Microsoft Global Secure Access

**Short description (for LinkedIn project field)**  
Designed and implemented a pragmatic Zero Trust Secure Service Edge for a startup BYOD environment using Microsoft Global Secure Access, Entra ID, Intune, and Conditional Access. Focused on securing company resources while deliberately preserving device ownership and user privacy.

**Longer version (for project details / featured section)**  
Designed and delivered a Secure Service Edge solution in a real startup BYOD environment (Windows + macOS).

Key elements:
• Microsoft Global Secure Access limited to the Microsoft 365 profile only (Private Access and Internet Access deliberately excluded to protect ownership/privacy)
• Conditional Access enforcing compliant device + GSA verified network + MFA
• User-driven enrollment with clear separation of work and personal profiles
• Automated offboarding that retires the device in Intune before deleting the Entra identity
• Explicit risk acceptance around universal tenant access to support partner collaboration
• Production hardening: QUIC disabled, IPv6 path controls, break-glass exclusions, report-only rollout first
• Supporting controls with Microsoft Purview and unauthorised access notifications

The design prioritised usable security and defensible trade-offs over maximum control. Particularly relevant for identity, GRC, and Zero Trust roles operating in high-autonomy or BYOD contexts.
